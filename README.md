Pesign is a centralized control-based platform delivering premium graphic design, customizable print products, and fast delivery across India. This repository (`pesigninfo-maker`) houses the core scalable SaaS architecture built for high-performance edge deployment.

## 🏗️ Core Architecture
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Radix UI / Framer Motion
- **Language:** TypeScript
- **Deployment:** Vercel (Edge-optimized)
- **Design System:** Mobile-first, minimal modern SaaS UI, strict Trust-Blue branding.
